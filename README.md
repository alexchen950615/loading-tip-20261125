One sharp, funny loading-screen tip for stressed developers and AI coding agents — 114 characters, one line.

## The tip

> Breathe. The AI already rewrote your code twice, blamed the cache, and is now Googling the error it just invented.

## Run

```bash
python3 main.py
```

This writes the tip to `/output/entry.txt` (UTF-8, single line, 1–200 chars, no trailing newline). `main.py` asserts the length and single-line gate before writing.
